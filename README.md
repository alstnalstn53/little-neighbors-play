# Little Neighbors test build

A private test build for the owner's phone. The game data in `game.bin` is encrypted and its key
is not in this repository, so the page does not open without the owner's link. This is not a
public release.

The other files are the Godot 4.7.2 web engine, MIT licensed. See `licenses/`.
